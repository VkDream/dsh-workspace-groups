# 工作区分区

把侧栏「工作区」按自建分区折叠分组，样式跟随内置侧栏（Codex 形态：淡灰分区标题、
展开不出箭头、悬停才显示数量与操作、菜单带图标与二级菜单）。

## 用法

- 标题行 **＋**：行内输入分区名，回车新建（Esc 取消）。
- 工作区行 **⋯ →「移动到分区」**：右侧展开分区列表，点哪个归哪个；列表底部可直接新建分区并归入。
- 工作区行 **⋯ →「更改图标」**：48 个常用表情符号，或输入任意字符；「清除」恢复默认。
- 分区行 **⋯**：重命名 / 更改图标 / 折叠 / 上移 / 下移 / 新建分区 / 删除分区。
- **拖拽**：拖到分区标题=归入；拖到另一个工作区=归入它的分区并排到它前面（顺序写 Host 持久顺序）。
- **置顶**：分区列表顶部默认有「置顶」，DSH 原生置顶的会话也显示在里面；不可删除。
- **会话**：悬停 ⋯ 或右键 → DSH 原生会话菜单（置顶、改名、分叉、复制 ID、归档）。
- **搜索**：标题过滤 + Host 对话内容搜索；标题行 ⋯ 里可切换显示已归档会话、添加工作区。

## 数据放在哪

分区、归属、图标只写浏览器本地存储 `dsh.ws-groups.v1`（另存一份 `.bak` 兜底）。
工作区注册表、目录、会话日志都不动；拖拽排序会写一次 Host 的持久顺序（与内置拖拽等价）。
卸载插件后分区配置失效，工作区注册本身不变。

## 边界

本插件占用侧栏 `sidebar.workspaces` 槽位，所以内置浏览器里未接入这里的能力不会出现：
悬浮详情卡、会话手动排序、按工作区树分组的视图选项、原生目录选择器。
会话的置顶/改名/分叉/归档走原生菜单，功能完整。
