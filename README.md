# DSH 工作区分区（Workspace Groups）

把 DeepSeek Harness 侧栏的「工作区」列表，变成 Codex 风格的可折叠分区：
自建分区、把工作区拖进分区、给分区/工作区换图标、顶部常驻「置顶」。

> 适配 DSH `0.2.2-rc.3`（Desktop/Web 客户端）。这是一个本地 bundle 插件，不是 npm 包。

## 功能

- **分区**：标题行 `＋` 新建；分区可重命名、折叠、上移/下移、删除
- **归置**：工作区 `⋯ → 移动到分区`，或直接把工作区拖到分区标题上
- **拖拽排序**：拖到另一个工作区行 = 归入同一分区并排到它前面（顺序写 Host 的持久顺序）
- **图标**：分区/工作区 `⋯ → 更改图标`，48 个常用表情或任意字符输入，可清除
- **置顶**：列表顶部默认常驻「置顶」分区，DSH 原生置顶的会话也显示在里面
- **会话**：悬停 `⋯` 或右键 → DSH 原生会话菜单（置顶、改名、分叉、复制 ID、归档）
- **搜索**：标题过滤 + Host 对话内容搜索
- **其他**：显示/隐藏已归档会话、添加工作区（输入绝对路径）、复制工作区路径

## 安装

1. 左侧「插件」→「添加插件 / 本地目录」，选择本仓库目录
2. 重启 DeepSeek Harness（客户端插件在启动时进组合清单）

命令行等价做法：

```js
// 在 DSH 会话里
plugin_manager({ action: 'install_bundle', target: 'F:/path/to/dsh-workspace-groups' })
```

## 卸载

左侧「插件」里停用/移除本插件并重启，侧栏会恢复内置工作区列表。
插件不修改 Host 的工作区注册表、目录或会话日志。

## 数据

分区、归属、图标只存在浏览器本地存储 `dsh.ws-groups.v1`（另存 `.bak` 兜底）。
拖拽排序会写一次 Host 的工作区显示顺序（与内置拖拽等价）。

## 已知限制

本插件占用侧栏 `sidebar.workspaces` 槽位（DSH 该槽位只允许一个占据者），
所以内置工作区浏览器里未接入这里的能力不会出现：

- 会话/工作区的悬浮详情卡
- 会话手动排序
- 按工作区树分组的视图选项
- 原生目录选择器（添加工作区改为输入路径）
